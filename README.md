1. Clone the Repo
bashgit clone https://github.com/yourusername/your-repo.git

2. Install Node Packages
npm install
(This recreates node_modules/ from package.json)

3. Install Python Packages
pip install flask pymongo flask-cors werkzeug dnspython

4. Run Both Servers
Terminal 1 — Flask:
python app.py
Terminal 2 — Expo:
npm run web
